# Format Forge privacy policy

Format Forge is designed to convert files on the user's device.

- Input files and converted outputs are not uploaded to Format Forge or to a third-party service.
- Browser conversions run inside the extension tab.
- Document and media conversions can be sent over an authenticated loopback connection to the optional Format Forge companion running on the same computer.
- The extension does not include analytics, advertising, tracking, or remote executable code.
- Files are kept in memory by the extension. The companion uses private temporary job directories and removes them after download or expiration.
- The extension stores only local settings, including the optional companion pairing token. It does not store input documents in Chrome storage.

The browser, operating system, LibreOffice, FFmpeg, and other locally installed tools may have their own policies and security characteristics.
