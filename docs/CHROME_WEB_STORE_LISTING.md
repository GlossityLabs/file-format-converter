# Chrome Web Store listing copy

## Name

Format Forge — File Format Converter

## Short description

Convert DOCX to PDF, PNG to JPG, MP4 to MP3, PDFs to images, and CSV to JSON. Private file conversion runs locally.

## Detailed description

Format Forge is a private file format converter for Chrome. Convert documents, PDFs, images, spreadsheets, presentations, audio and video without uploading files to a cloud conversion service.

Popular conversions include:

- DOCX, DOC, ODT, RTF and TXT to PDF
- PNG, JPG and WebP to another image format or PDF
- PDF pages to PNG or JPG images in a ZIP
- CSV to JSON and JSON table data to CSV
- XLSX, XLS, ODS and CSV to PDF
- PPTX, PPT and ODP to PDF
- MP3, WAV, FLAC, M4A, AAC, OGG and Opus audio conversions
- MP4, MOV, MKV, WebM, AVI and M4V video conversions, including MP4 to MP3 or GIF

Image, PDF, CSV and JSON conversions run directly in Chrome. High-fidelity Office, audio and video conversions use the optional Format Forge Companion on the same computer, backed by LibreOffice and FFmpeg.

Privacy is part of the architecture: Format Forge has no accounts, analytics, advertising, cloud upload service or developer-operated conversion API. Source files and converted results stay on the user's device.

Format Forge is open source under the Apache License 2.0.
